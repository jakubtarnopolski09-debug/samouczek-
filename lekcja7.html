Lekcja 7: Sztandary na Wieżach (Pozycjonowanie CSS)

Opanowaliśmy Flexbox, ale czasem element musi zostać "wyrwany" z normalnego układu i przytwierdzony w konkretnym miejscu, np. sztandar wiszący poza obrysem muru. Do tego celu służy właściwość position.

Kluczowe właściwości pozycjonowania:

  • position: relative; - Element pozostaje w swoim miejscu, ale staje się punktem odniesienia dla pozycjonowanych dzieci.
  • position: absolute; - Wyrwa element z dokumentu. Ustawia się go względem najbliższego rodzica, który ma position: relative.
  • top, right, bottom, left - Służą do przesuwania elementu o konkretne wartości (np. piksele).

Kod CSS do wstawienia w <head>:

zamek.html (Style CSS)
<style> .mur-obronny { position: relative; background-color: #4a3525; height: 200px; } .sztandar { position: absolute; top: -20px; right: 15px; background-color: #a62c2c; width: 30px; height: 50px; } </style>

Zadania Architekta:

Ćwiczenie 1: Ustalenie punktu odniesienia

Odszukaj klasę .mur-obronny w swoim pliku CSS i dopisz position: relative;, aby zamienił się w fundament dla flagi.

Ćwiczenie 2: Wywieszenie sztandaru

Dla klasy .sztandar ustaw position: absolute;. Zauważysz, że element przestaje rozpychać inne bloki.

Ćwiczenie 3: Korekta położenia

W klasie .sztandar użyj top: -20px; oraz right: 15px;, aby wysunąć flagę lekko ponad mur i przysunąć do prawej krawędzi.

Stan Budowy

Faza 7: Pozycjonowanie wdrożone. Zamek zyskuje na szczegółowości dzięki elementom, które mogą swobodnie nakładać się na siebie poza standardową siatką.

Księga Architekta

Księga Architekta opisuje pozycjonowanie CSS jako technikę, która pozwala „wyrwać” element z normalnego układu strony i umieścić go dokładnie tam, gdzie chcemy. Dzięki temu zamek przestaje być tylko sztywną siatką – zaczyna żyć detalami, takimi jak sztandary, które mogą wystawać poza mury.

Najważniejsze zasady pozycjonowania:

  • position: relative – tworzy punkt odniesienia, ale nie usuwa elementu z układu
  • position: absolute – usuwa element z normalnego przepływu i ustawia go względem rodzica
  • top / right / bottom / left – pozwalają precyzyjnie przesuwać element w dowolnym kierunku

Można to porównać do architektury zamku, w której:

  • mur obronny jest fundamentem i stabilną bazą konstrukcji
  • sztandar jest lekkim elementem dekoracyjnym, który może „wychodzić” poza strukturę
  • CSS decyduje, co jest przytwierdzone, a co może swobodnie się przemieszczać

Najważniejsza zasada, którą musi zapamiętać każdy architekt: element z position: absolute zawsze szuka najbliższego rodzica z ustawionym position: relative. Jeśli go nie znajdzie, odnosi się do całego okna przeglądarki, jak sztandar zawieszony w pustce poza murami zamku.
