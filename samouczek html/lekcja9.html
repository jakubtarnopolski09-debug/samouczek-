Lekcja 9: Tchnij Życie w Zamek (Animacje, Menu i RWD)

Mury stoją, formularze działają. Czas sprawić, by zamek ożył i dostosowywał się do każdego urządzenia, z którego korzysta lord. W tej lekcji wprowadzamy trzy zaawansowane techniki: animacje CSS, rozwijane menu (Dropdown) oraz RWD (Responsive Web Design).

1. Animacje (Keyframes)

Aby flaga dumnie powiewała na wietrze, wykorzystujemy dyrektywę @keyframes, która definiuje stany początkowe, pośrednie i końcowe ruchu.

2. Menu Rozwijane (Hover & Podlisty)

Sekretem menu rozwijanego jest ukrycie podrzędnej listy (display: none;) i wyświetlenie jej (display: block;) dopiero, gdy myszka najedzie na element główny (pseudoklasa :hover).

3. Responsywność (Media Queries)

Nie każdy lord czyta raporty na wielkim pergaminie. Na małych zwojach (smartfonach) zamek musi zmienić układ z wielokolumnowego na jedno-kolumnowy przy użyciu @media.

Kompletny Zestaw Kodów CSS:

style.css
/* --- 1. ANIMACJA FLAGI --- */ @keyframes powiewanie { 0% { transform: rotate(0deg); } 100% { transform: rotate(-15deg) skewY(-5deg); } } .sztandar-animowany { transform-origin: left top; /* Punkt zaczepienia (drzewce) */ animation: powiewanie 1.5s infinite alternate ease-in-out; } /* --- 2. MENU ROZWIJANE --- */ .podmenu { display: none; /* Domyślnie ukryte */ position: absolute; background-color: #2b1d11; } .element-menu:hover .podmenu { display: block; /* Pokaż gdy myszka nad .element-menu */ } /* --- 3. RESPONSIVITY (RWD) --- */ @media (max-width: 768px) { .uklad-zamku { flex-direction: column; /* Kolumny układają się jedna pod drugą */ width: 100%; } }

Zadania Architekta:

Ćwiczenie 1: Wpraw flagę w ruch

Skopiuj dyrektywę @keyframes do swojego arkusza CSS, a następnie dodaj właściwość animation do klasy swojej flagi wywieszonej w poprzedniej lekcji. Punkt transform-origin: left top; zapobiegnie "odrywaniu" się flagi od masztu.

Ćwiczenie 2: Ukryta zbrojownia

Stwórz w HTML listę <ul>, a w jednym z <li> zagnieźdź kolejną listę z klasą .podmenu. Wykorzystaj podany wyżej kod CSS ze struktury :hover, aby podlista pokazywała się dopiero po najechaniu kursorem.

Ćwiczenie 3: Przygotowanie na mobilnych gońców (RWD)

Na samym dole pliku CSS dodaj sekcję @media (max-width: 768px). Wewnątrz niej zmień właściwości swojego głównego kontenera Flexbox, nadając mu flex-direction: column;. Zmniejsz szerokość okna przeglądarki, aby przetestować efekt punktu załamania (breakpoint).

Księga Architekta

Księga Architekta opisuje tę fazę rozwoju zamku jako moment, w którym statyczna konstrukcja zaczyna reagować na czas, ruch i urządzenie użytkownika. CSS przestaje być tylko układem – staje się systemem zachowań: animuje elementy, ukrywa sekrety i zmienia strukturę w zależności od wielkości ekranu.

Trzy filary ożywienia zamku:

  • Animacje (@keyframes) – definiują ruch elementów w czasie, tworząc płynne przejścia między stanami
  • Menu rozwijane (:hover) – pozwala ukrywać i odkrywać sekcje interfejsu w zależności od interakcji użytkownika
  • Media Queries (@media) – dostosowują układ zamku do różnych rozmiarów ekranów

Można to porównać do działania żywego systemu obronnego:

  • flagi na wieżach poruszają się jakby reagowały na wiatr i czas
  • zbrojownia ukrywa swoje sekrety, ujawniając je tylko wtajemniczonym
  • mury zmieniają swój układ, gdy zamek przenosi się na mniejsze pergaminy (ekrany)

Dzięki połączeniu tych mechanizmów zamek przestaje być statycznym projektem, a zaczyna zachowywać się jak żyjąca struktura, która reaguje na obecność użytkownika i warunki otoczenia.
