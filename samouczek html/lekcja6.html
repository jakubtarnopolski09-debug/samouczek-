Lekcja 6: Szyki Bojowe i Architektura (Układ Flexbox i Kolory)

Aby nasz zamek wyglądał jak na makiety, musimy wdrożyć arkusz stylów CSS. Najpierw ustalimy tło świata, a następnie użyjemy właściwości display: flex, która rozkaże kolumnom stać obok siebie, a nie jedna pod drugą.

Kluczowe właściwości układu:

  • display: flex; - Aktywuje tryb elastycznego kontenera. Wszystkie dzieci (kolumny) ustawią się w jednym rzędzie.
  • flex: 1; - Pozwala elementowi rosnąć i wypełniać dostępną przestrzeń.
  • background-color: - Definiuje barwę tła (używamy kodów Hex, np. #2b1d11).

Kod CSS do wstawienia w <head>:

zamek.html (Style CSS)
<style> body { background-color: #2b1d11; color: #d4af37; margin: 0; } main { display: flex; justify-content: center; gap: 25px; padding: 20px; } .kolumna-lewa, .kolumna-prawa { width: 25%; } .kolumna-srodkowa { width: 50%; background: #faf4e8; } </style>

Zadania Architekta:

Ćwiczenie 1: Malowanie nieba i ziemi

W sekcji <head> stwórz znacznik <style> i ustaw dla body ciemnobrązowe tło (#2b1d11).

Ćwiczenie 2: Formowanie szyku kolumn

Dodaj regułę dla znacznika main i wpisz display: flex;. Zobacz w podglądzie, jak kolumny natychmiast wskakują obok siebie.

Ćwiczenie 3: Rozstawienie baszt

Ustaw szerokości kolumn (width) według proporcji: boczne 25%, środkowa 50%.

Księga Architekta

Księga Architekta opisuje Flexbox jako jedno z najważniejszych narzędzi CSS3, które pozwala porządkować elementy strony w sposób elastyczny i logiczny. Zamiast dawnych, sztywnych metod układu, takich jak float, otrzymujemy system, który sam dostosowuje się do dostępnej przestrzeni i układu ekranu.

Najważniejsze właściwości, które poznaliśmy w tej lekcji:

  • display: flex – uruchamia elastyczny tryb układu i ustawia elementy w jednym rzędzie
  • flex: 1 – pozwala elementom rosnąć i równomiernie wypełniać przestrzeń
  • background-color – nadaje światu barwy i buduje klimat zamku
  • justify-content – kontroluje rozmieszczenie kolumn w poziomie

W praktyce oznacza to, że nasz zamek zaczyna zachowywać się jak dobrze zaprojektowana struktura architektoniczna:

  • lewa wieża stabilnie trzyma swoją pozycję
  • sala tronowa zajmuje centralne, najważniejsze miejsce
  • prawa wieża równoważy całą konstrukcję

Dzięki Flexboxowi układ przestaje być chaotyczny, a staje się kontrolowaną, żywą strukturą – jak prawdziwy cyfrowy zamek, który reaguje na zmiany przestrzeni i rozmiaru ekranu.
